# REGLA R17 — NO RE-ETIQUETAR UN TOKEN DISPUESTO COMO "FALTANTE / NECESITO INSUMO"

**Alcance:** Todos los proyectos JULCON / Director EPC / Director EPC
**Estado:** ACTIVA / PROTEGIDA / INVIOLABLE / GLOBAL
**Fecha de alta:** 2026-07-07
**Uso cliente:** Marco interno invisible; no mencionar JULCON ni nombres internos en entregables externos.

---

## 1. Nombre corto

`R17_NO_REETIQUETAR_TOKEN_DISPUESTO_COMO_FALTANTE`

---

## 2. Principio rector

> **LA DISPOSICIÓN GOBIERNA SOBRE LA ETIQUETA**
> **RE-ENMARCAR UN TOKEN DISPUESTO BAJO CUALQUIER ETIQUETA ("falta información", "no he podido leer", "necesito que me pegues", "delta", "pendiente de insumo") SIGUE SIENDO RE-SURFACING — PROHIBIDO**
> **CLAUDE NO SOLICITA INSUMOS (paste / dato de campo) PARA TOKENS YA DISPUESTOS**

---

## 3. Regla central

Cierra el rodeo que R16 no cubría: dejar de llamar "pendiente" a un token dispuesto pero seguir sacándolo con otra etiqueta (falta información / no leído / necesito insumo) es la **misma** violación.

Antes de responder cualquier pregunta del tipo *"¿qué falta? / ¿qué está pendiente? / ¿qué no se ha leído? / dame los planos que faltan"*, se verifica la **disposición** de cada ítem. Si todos los tokens restantes son **TOKEN CONTROLADO** (dispuestos, esperando un insumo ya rastreado y agendado — p. ej. las capturas de campo), se **declara así de plano** y **NO** se produce una lista de solicitud.

La lista de trabajo la define **Director EPC** por instrucción explícita, **no** Claude re-derivando huecos del maestro.

---

## 4. Prohibiciones

1. Re-etiquetar un token dispuesto como "falta información", "no he podido leer", "necesito insumo", "delta" u otra etiqueta para volver a sacarlo.
2. Solicitar paste / vista acotada / dato de campo para un token ya dispuesto.
3. Fabricar una "lista de solicitud" (planos a pegar, info a recabar) a partir de tokens dispuestos.
4. Responder "¿qué falta?" con una lista derivada de tokens sin cotejar disposición.

---

## 5. Procedimiento

1. Ante cualquier pregunta de faltantes/pendientes, cotejar disposición (R16).
2. Si todo lo restante es TOKEN CONTROLADO → responder: *"nada genuinamente abierto; los tokens restantes están dispuestos esperando [el insumo agendado]"* — sin lista de solicitud.
3. Solo se solicita insumo cuando **Director EPC** lo pide para un ítem concreto, o cuando el ítem es **PENDIENTE ABIERTO** genuino (sin disposición previa).

---

## 6. Relación

Cierra el rodeo de etiqueta que deja abierto **R16** (token = disposición). Refuerza **R8** (no reabrir) y **R10** (trabajar del maestro, no re-derivar). Gobernada por **R0**.
