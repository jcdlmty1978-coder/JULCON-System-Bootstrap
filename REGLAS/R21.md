# REGLA R21 — ACTUALIZACIÓN EN SITIO PRESERVANDO ESTÉTICA

**Sistema:** JULCON v13.1  
**Ámbito:** REGLA_GLOBAL (todos los proyectos)  
**Estado:** REGLA_PROTEGIDA / ACTIVA / APLICACIÓN_INMEDIATA

## 1. Criterio rector

Al actualizar el Libro Maestro o cualquier entregable existente, se edita el archivo vigente que el usuario sube **EN SITIO**, preservando exactamente su estética y plantilla: fuentes, colores, fills, merges, anchos de columna, alturas de fila, orden de hojas, estructura, logotipos e imágenes embebidas.

## 2. Cláusulas obligatorias

1. **Prohibido reconstruir el entregable en un archivo nuevo con formato propio del agente.** La actualización debe ser quirúrgica: insertar o poblar celdas, columnas u hojas nuevas con estilo heredado, sin alterar el aspecto existente.
2. Si el archivo llega con extensión engañosa —por ejemplo `.XLS` que en realidad es OOXML/XLSX— se debe detectar el tipo real mediante firma o *magic bytes* y editar con la herramienta correcta.
3. Antes de guardar, se debe verificar empíricamente que la herramienta elegida preserva medios embebidos (`xl/media`, drawings, relaciones e imágenes). Si los destruye, se debe usar parcheo XML directo u otro método que conserve íntegramente los medios.
4. La verificación post-edición es obligatoria: realizar diff celda a celda contra el original. Solo deben diferir las celdas intencionalmente modificadas; se debe contar y reportar cada diferencia.
5. Antes de tocar el archivo, conservar una copia binaria íntegra del original para cotejo y recuperación.
6. No se considera cumplida la regla si el archivo conserva datos pero pierde estética, logotipos, imágenes, fórmulas, nombres definidos, vínculos, formatos condicionales, validaciones o configuración de impresión.

## 3. Evidencia mínima de cumplimiento

- Archivo original identificado.
- Tipo real del contenedor verificado.
- Herramienta o método de edición registrado.
- Conteo de celdas intencionalmente modificadas.
- Confirmación de preservación de medios y drawings.
- Comparación post-edición contra el original.

## 4. Prohibiciones

- Crear un LM sustituto con estética nueva sin autorización expresa.
- Convertir formatos de manera destructiva.
- Eliminar o reemplazar imágenes, logotipos o elementos gráficos.
- Cambiar orden de hojas, anchos, alturas, merges o estilos fuera del alcance autorizado.
- Declarar preservación sin verificación empírica.

## 5. Motivo / caso origen

10-jul-2026, otra localidad: se levantó un Libro Maestro nuevo con estética propia en lugar de actualizar en sitio el archivo real del usuario.
