# REGLA R23 — AUDITORÍA DE CANTIDADES CONTRA DOCUMENTO RECTOR

**Sistema:** JULCON v13.1  
**Ámbito:** REGLA_GLOBAL  
**Estado:** REGLA_PROTEGIDA / ACTIVA / APLICACIÓN_INMEDIATA

## 1. Criterio rector

Todo catálogo, Libro Maestro o despiece generado con cobertura de lectura **parcial** debe re-auditarse **partida por partida contra los documentos rectores** cuando la cobertura documental se complete, antes de ratificarse o utilizarse para RFQ o CAPEX.

## 2. Cláusulas obligatorias

1. **Expansión aritmética de cláusulas “por cada X”.** Toda obligación del rector expresada como razón —por ejemplo “un gabinete por cada juego tripolar” o “dos UCB por interruptor”— se debe expandir contando las instancias reales de `X` dentro del alcance. La cantidad resultante se escribe explícitamente y conserva memoria de cálculo.
2. **Unidad cotizable obligatoria.** Un proveedor cotiza cantidades, no conceptos abstractos. `LOTE` o `PZA` usados indebidamente para cables, conductores o materiales lineales deben convertirse a unidades cotizables como m, kg o pzas, con memoria de cálculo. Los lotes de juegos deben expresarse como `1 lote (N pzas)`.
3. **Frontera antidoble-conteo.** Toda obra o suministro que aparezca en dos frentes del mismo proyecto exige una frontera declarada con **titular único**. El frente no titular se registra como interfaz explícita. Todo doble conteo detectado constituye hallazgo bloqueante para RFQ.
4. **Informe previo a corrección.** El resultado de la auditoría debe informarse antes de generar el entregable corregido, identificando errores por frente, partida, celda y fuente.
5. Ninguna cantidad inferida por plantilla, analogía o catálogo previo puede ratificarse sin cotejo con el alcance y rector del proyecto actual.
6. Toda cantidad debe conservar estado de certeza y procedencia: confirmada, calculada, estimada, pendiente de RFI o no aplicable.

## 3. Gate obligatorio antes de RFQ / CAPEX

Antes de liberar un catálogo o LM se debe confirmar:

- cobertura documental completa o brechas declaradas;
- cantidades expandidas desde obligaciones por razón;
- unidades cotizables;
- memoria de cálculo;
- fronteras de alcance;
- ausencia de doble conteo;
- trazabilidad a documento, sección, plano o lista rectora.

Si falta cualquiera de estos puntos, el estado es:

`AUDITORIA_CANTIDADES_PENDIENTE / RFQ_BLOQUEADO / CAPEX_NO_RATIFICADO`

## 4. Motivo / caso origen

14-jul-2026, otra localidad: un gabinete centralizador quedó en 2 pzas cuando el rector exigía 3 —uno por cada juego tripolar: TC, TPI de facturación y TPI de protección—; el cable de 230 kV estaba expresado como `3 PZA` en lugar de 690 m; y existían fosas y terminales duplicadas entre los frentes A3 y B1.

## 5. Relación con otras reglas

- Gobernada por R0, R2, R5, R4 y R3.
- Refuerza la unidad cotizable prevista en R12.
- Alimenta los gates de RFQ, CAPEX y emitibilidad.
- Se ejecuta antes de R24 cuando el checklist de ingenierías dependa de cantidades o frentes.
